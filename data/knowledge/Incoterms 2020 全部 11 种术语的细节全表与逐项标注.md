## 二、风险转移的细节与例外

### 2.1 默认规则之外的两个“提前转移”触发点

**（1）买方未履行通知义务。** 若买方有义务就交货时间、交货点、承运人名称或运输方式给予卖方充分通知，而买方未通知，风险并非“等到实际交货时才转移”，而是**从约定的交货日期或交货期限届满时**转移给买方，**而非从实际交货时**转移。

**（2）货物尚未“特定化”时，风险不提前转移。** 上述提前转移的前提是货物已**划归合同项下**（特定化），通常体现为刷唛、标识、与其他同类货物清楚分开。若货物仍为种类物，风险不能在交货之前转移给买方。

### 2.2 风险的范围本身有限

Incoterms 中的“风险”**仅指货物灭失或损坏的风险**，不包括违约风险。若货物在风险转移**前**已存在瑕疵（如包装不符、内在缺陷），即便风险已转移，买方仍可基于卖方违约主张救济，卖方不能仅以“风险已转移”抗辩。

### 2.3 C 组风险与费用的分裂（重点标注）

| 术语          | 风险转移           | 费用终点       | 实务含义                                     |
| :------------ | :----------------- | :------------- | :------------------------------------------- |
| **CFR / CIF** | 装运港**装上船**   | **目的港**     | 卖方付海运费，但海上风险由买方承担           |
| **CPT / CIP** | **交给第一承运人** | **指定目的地** | 卖方付全程运费，但交第一承运人后的风险归买方 |

CPT/CIP 的风险转移点可能**早于**买方对承运人的认知——若涉及多式联运，交货在货物交给**第一承运人**时即完成，而该承运人可能并非买方选定或知晓的。CIF/CFR 下，卖方义务以货物**装上船**为履行完毕节点，而非“越过船舷”这一旧表述。

## 三、费用分摊的细颗粒度拆解

### 3.1 装货、卸货、码头操作费（THC）

| 费用项目       | 关键规则                                                     | 细节                                                         |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **起运地装货** | EXW **买方装**；FCA **视地点**：卖方场所卖方装，其他地点买方/承运人处理；FAS **买方装船**；FOB 及以上卖方负责起运地装货 | EXW 是唯一明确**卖方不装货**的术语，“置于买方处置”即可，买方需自备装货劳力和设备 |
| **目的地卸货** | **DAP/DDP 买方卸；DPU 卖方卸**                               | DAP 与 DPU 的唯一实质区别就是**谁卸货**：DAP 在“运输工具上准备卸载”时交货，DPU 在“完成卸货后”交货 |
| **装运港 THC** | **FOB 下默认卖方承担**（属装船前费用），但可通过合同明示转移或分摊 | 建议写法：“FCA [地点] Incoterms® 2020, THC for seller’s account”或约定比例 |
| **目的港 THC** | 取决于术语：CFR/CIF 卖方付海运费，但目的港 DTHC 的归属需看运输合同与提单条款；C 组下卖方费用止于“运费付至”，目的港卸货及后续 THC 通常归买方 | C 组目的港的 THC 争议高发，建议在运输合同或买卖合同中单独明示 DTHC 的承担方 |

### 3.2 关税、税费

- **出口关税/税费**：**EXW 买方承担**，其余 10 种术语**卖方承担**。
- **进口关税、增值税（VAT）、消费税**：**仅 DDP 由卖方承担**；DAP、DPU、C 组、F 组均由**买方**承担。
- **过境国税费**：若运输途经第三国产生关税或手续费，归属取决于该费用是否落在卖方的“费用止于”节点之内；DDP 下卖方承担至完成进口清关为止，过境费用通常也归卖方。

### 3.3 保险费用

| 术语      | 卖方是否必须投保             | 最低险别                                     | 保额               |
| :-------- | :--------------------------- | :------------------------------------------- | :----------------- |
| **CIF**   | **是**                       | **ICC(C)**（协会货物条款 C，限制性列明风险） | 合同价值 **×110%** |
| **CIP**   | **是**                       | **ICC(A)**（一切险，2020 版重大升级）        | 合同价值 **×110%** |
| 其余 9 种 | **无义务**（由各方自行评估） | —                                            | —                  |

CIP 的 ICC(A) 是 Incoterms 2020 相对 2010 的实质性变化：2010 版 CIP 也仅要求 ICC(C)，2020 版提升为 ICC(A)。CIF 维持 ICC(C) 最低标准不变。保险须以**合同同一货币**计价，且覆盖**买方在运输途中的风险**（而非卖方交货前的风险）。

## 四、逐术语细节标注

### EXW：卖方义务最少的极端

- **装货义务不在卖方**。A2 仅要求“置于买方处置”，**不要求装上任何收货车辆**；装货劳力和设备由买方安排并承担费用。
- **出口清关归买方**。这是 EXW 与 FCA 的根本区别，也是实务中买方在出口国难以作为清关主体时的**高危条款**。若买方无法在出口国办理出口手续，应改用 FCA。
- **风险与费用同点转移**，无分裂。

### FCA：装货义务取决于“交货地点”

- **卖方场所交货**：卖方须将货物**装上买方指定的运输车辆**，风险在装上后转移。
- **其他地点交货**：货物在卖方运输工具上、**可供买方承运人卸载**时即完成交付，卸货由买方/承运人负责。
- **2020 版新增的装船提单机制**：在 FCA + 海运场景下，双方可约定买方指示承运人在货物装船后向卖方签发**已装船提单（on board B/L）**，以解决信用证对装船提单的要求与 FCA 交承运人即完成交货之间的时间错位。

### FAS：船边，不是船上

- 卖方义务止于将货物**置于船边**（码头或驳船），**装船义务和费用归买方**。
- 风险在“置于船边”时转移，而非装船时；这与 FOB 的“装上船”形成清晰界线。

### FOB：装船费用内部的进一步细分

FOB 的默认规则是卖方负责将货物**装上船**，但“装船”内部还包含**理舱（stowed）和平舱（trimmed）** 两项作业。若合同仅写“FOB”，卖方是否承担理舱/平舱费可能存在解释空间；实务中通过**FOB 变形**加以明确：

- **FOB stowed**：卖方承担理舱费；
- **FOB trimmed**：卖方承担平舱费；
- **FOB stowed and trimmed**：卖方承担理舱和平舱费。

### CFR / CIF：费用到目的港，风险留在装运港

- 卖方须支付将货物运至**指定目的港**的海运费，但风险在**装运港装上船**时已转移。
- CIF 额外要求卖方投保，但保险是**为买方利益**而设，承保的是**买方风险期间**（装船后至目的港）的损失，并非将风险拉回卖方。
- 二者仅适用于**海运和内河运输**，且通常涉及可转让提单，以便买方在运输途中转售货物。

### CPT / CIP：交给“第一承运人”即风险转移

- 若涉及多式联运，交货和风险转移在货物交给**第一承运人**时完成，而非在最终目的地或交给后续承运人时。
- **交货点未约定时的默认规则**：若双方未明确具体的交货点，风险在货物交给**第一承运人**时转移，交货点由卖方选择。
- CIP 的 ICC(A) 义务是 2020 版区别于 CIF 的核心点；CIF 仅需 ICC(C)，CIP 须 ICC(A)。

### DAP：准备卸载，不是卸载后

- 风险转移节点为货物在目的地**运输工具上、准备卸载**时；卸货风险和费用归买方。
- 若卖方无法确保目的地具备卸货条件或卸货由买方控制，DAP 比 DPU 更安全。

### DPU：唯一由卖方在目的地卸货的术语

- DPU 是 **DAT 的更名与扩展**：交货地点从“运输终端”扩展为“任何指定目的地”，但核心义务不变——**卖方负责卸货**，交货在卸货完成后发生。
- 与 DAP 的唯一实质区别是**卸货义务的归属**；DAP 在卸载前交货，DPU 在卸载后交货。
- 若约定的目的地**不具备卸货条件**（无设备、无准入），卖方不应接受 DPU。

### DDP：进口清关归卖方，但卸货不归卖方

- DDP 是 11 种术语中**卖方责任最大**的一种，卖方须完成**进口清关、支付进口关税、增值税及其他税费**，买方收到的是“已完税”货物。
- **但 DDP 不包含卸货**：风险在目的地运输工具上准备卸载时转移，卸货仍归买方。DDP 常被误读为“卖方包到门内一切”，实际上“门内卸货”不在 DDP 的默认义务之内。
- **DDP 的结构性风险**：卖方须在进口国作为进口记录人（importer of record）或与当地报关主体协调。若卖方对进口国税制、海关要求不熟悉，或无法在目的地国完成清关主体资格，DDP 可能导致货物滞留、仓储费和清关罚金由卖方承担。**替代方案是 DAP**：进口清关和税费转由买方负责，卖方风险显著收窄。

## 五、通知义务：细节与后果

通知义务在 Incoterms 2020 中不是“软性提示”，未履行可能直接改变**风险转移时点**或触发额外费用承担。

| 术语组                 | 卖方通知义务                                         | 买方通知义务（关键细节）                                     |
| :--------------------- | :--------------------------------------------------- | :----------------------------------------------------------- |
| **EXW、DAP、DPU、DDP** | 发出**为买方提取货物所需的任何通知**                 | 买方有权决定期限内的提货时间/地点时，须给卖方**充分通知**    |
| **CPT、CIP、CFR、CIF** | 发出**已按 A2 完成交货的通知**及买方收取货物所需通知 | 买方有权决定发货时间/目的地收货点时，须充分通知              |
| **FCA**                | 就完成交货或买方指定人未按时提货发出充分通知         | 须通知：**承运人/指定人名称、收货时间、运输方式（含安全要求）、收货点** |
| **FAS、FOB**           | 就完成交货或买方指定船舶未按时到达发出充分通知       | 须通知：**船舶名称、装货点、运输安全要求、选择的交货时间**   |

**FCA、FAS、FOB 对买方通知的要求最重**，因为这三个术语下卖方需要买方提供船舶/承运人信息才能履行交货；买方未通知可能导致卖方无法交货，风险仍可能依“约定期限届满”规则提前转移。

## 六、D 组三术语的一页定位

|              | **DAP**                        | **DPU**                  | **DDP**                              |
| :----------- | :----------------------------- | :----------------------- | :----------------------------------- |
| 进口清关     | 买方                           | 买方                     | **卖方**                             |
| 进口关税/VAT | 买方                           | 买方                     | **卖方**                             |
| 目的地卸货   | **买方**                       | **卖方**                 | **买方**                             |
| 风险转移     | 运输工具上准备卸载时           | **完成卸货后**           | 完成进口清关、运输工具上准备卸载时   |
| 卖方风险等级 | 中高                           | 高（含卸货）             | **最高**（含清关+税费，但不含卸货）  |
| 典型适用     | 买方有进口能力、目的地卸货可控 | 卖方能控制目的地卸货条件 | 卖方在进口国有清关主体资格与税务能力 |

## 七、实务细节红线清单

1. **CIF/CFR 买方不能因为“卖方付了运费”而认为卖方承担海上风险**；风险在装运港装船时已转移，保险索赔与风险归属是两回事。
2. **集装箱海运优先考虑 FCA/CPT/CIP，而非 FOB/CFR/CIF**。传统海运术语在集装箱场景下容易产生装船前风险空档和 THC 双重/争议收费；ICC 专门就此发布过 FCA/CPT 最佳实践指南。
3. **EXW 下买方须自行完成出口清关**；若买方在出口国无清关能力，改用 FCA，不要用 EXW 硬撑。
4. **DDP 不等于“卖方包卸货”**；DDP 的终点是“已完税、运输工具上准备卸载”，卸货仍归买方。
5. **CIP 在 2020 版已升至 ICC(A)，CIF 仍为 ICC(C)**；报价和投保时不能沿用 2010 版的旧习惯将二者等同。
6. **风险提前转移以“货物特定化”为前提**；货物未划归合同项下时，买方未通知并不能使风险在交货前转移。
7. **FCA 的装货义务取决于交货地点**：卖方场所卖方装，其他地点卖方不负责卸到承运人车辆/场地。
8. **FOB 内部的理舱/平舱费用需用变形明确**；仅写“FOB”时，装船作业中的这部分费用归属可能在争议中处于不确定状态。
