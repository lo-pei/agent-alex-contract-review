# 外贸合同快审·小律同学AI

## 技能定位

面向中国中小外贸企业（年出口额500万-5000万人民币），提供快速、专业、可落地的进出口合同条款审查服务。

**核心价值：**

- 30分钟内完成一份合同的初步审查
- 量化风险等级，优先级排序
- 提供具体可操作的修改建议
- 适配中国法律体系与国际商事惯例

## 适用范围

✅ 适用：

- 国际货物买卖合同（Sales Contract / Purchase Order）
- 框架协议（Framework Agreement）
- 分销/代理协议（Distribution / Agency Agreement）
- OEM/ODM加工协议

❌ 不适用：

- 技术进出口合同（需专门技术进出口审查）
- 服务贸易合同（需单独评估）
- 跨境投资/并购协议

## 审查流程（三步法）

### 文件处理与技能协作

1. 用户提供 `.docx`、`.doc` 或 `.pdf` 时，先用 `Read` 获取元数据，再按搜索/分页策略读取正文，不要求用户重复粘贴。
2. 同时激活 `xiaolv-contract-review`：本技能负责外贸专项风险，`xiaolv-contract-review` 负责复制审查副本、批注和修订流程；两者冲突时，以不改动原件和保留审阅痕迹为准。
3. 涉及中国法、外国法、国际条约、出口管制或制裁结论时，同时激活 `xiaolv-legal-analysis`，并在作出判断前调用 `search_law`。跨境、外国法和国际制裁使用 `scope: "international"`。
4. 用户要求审阅稿时，用 `Edit`/`Write` 生成带批注或修订的 `.docx`；用户只要求风险清单时可直接输出结构化报告。

### 第一步：合同要素提取（5分钟）

快速提取以下关键信息：

| 要素     | 说明                            |
| -------- | ------------------------------- |
| 合同双方 | 买方/卖方名称、注册地、联系人   |
| 货物描述 | 品名、规格、数量、单价、总价    |
| 贸易术语 | FOB/CIF/EXW等（Incoterms 2020） |
| 付款方式 | T/T、L/C、D/P、D/A              |
| 交货期   | 最迟装运日期                    |
| 目的地   | 目的港/目的地国家               |
| 争议解决 | 仲裁机构/管辖法院               |

### 第二步：12模块逐项审查（20分钟）

按以下12个模块逐项审查，每个模块独立评分：

#### 模块1：合同主体与形式

- 双方主体资格是否完整（公司名称、注册号、地址）
- 合同形式是否完整（签字盖章、日期、份数）
- 授权代表是否有有效授权

#### 模块2：货物描述与规格

- 品名、规格、型号是否明确具体
- 质量标准是否可验证（国标/行标/买方标准）
- 样品确认条款是否完善

#### 模块3：价格与贸易术语

- 单价与总价是否一致
- 贸易术语使用是否准确（Incoterms 2020）
- 价格调整机制是否合理（汇率波动、原材料涨价）
- 费用分担是否清晰（运费、保险、关税、港杂费）

**常见风险点：**

- FOB vs CIF责任边界不清
- 未约定汇率波动承担方
- 未明确关税承担方

#### 模块4：付款方式与期限

- 付款比例是否合理（预付款≥30%为佳）
- 付款时间节点是否明确
- 信用证条款是否与合同一致
- 逾期付款违约金是否约定

**风险分级（卖方视角，口径与 `references/payment-terms.md` 一致）：**

- 🟢 低风险：预付款比例较高且余款凭正本提单或信用证结算
- 🟡 中风险：T/T 30% 预付 + 70% 见提单副本；D/P 付款（买方拒付风险）
- 🟠 高风险：D/A 承兑交单、无担保的部分赊销
- 🔴 致命风险：O/A 全额赊销（无担保）、100% 尾款后付

#### 模块5：交货与运输

- 交货期是否明确具体
- 分批装运是否允许
- 转运是否允许
- 装运通知义务是否约定
- 运输方式与路线是否明确

#### 模块6：检验与验收

- 检验机构是否约定（SGS/BV/CCIC）
- 检验时间与地点是否明确
- 质量异议期是否合理
- 索赔期限是否充分

#### 模块7：包装与标记

- 包装标准是否符合运输要求
- 唛头是否明确
- 危险品包装是否符合IMDG/IATA规定

#### 模块8：违约责任

- 延迟交货违约金是否合理（每日0.05%-0.1%）
- 质量违约赔偿是否明确
- 违约金上限是否约定（通常不超过合同总额5%-10%）
- 解除合同条件是否清晰

#### 模块9：不可抗力

- 不可抗力范围是否明确（疫情、战争、自然灾害、政府行为）
- 通知义务是否约定（通常在事件发生后14天内）
- 证明文件要求是否合理
- 合同终止条件是否明确

#### 模块10：知识产权

- 产品是否侵犯第三方知识产权
- 知识产权归属是否明确（OEM场景）
- 侵权责任如何承担
- 品牌授权是否有效

#### 模块11：合规与制裁

- 出口管制合规（中国出口管制法）
- 目的国制裁/禁运风险
- 反洗钱合规
- 数据跨境传输合规（如涉及个人信息）

本模块的国家/地区名单、管制清单、制裁主体和法律效力状态均为动态信息。`references/compliance-checklist.md` 只能用于确定检索项，不能直接作为现行名单或法律依据；必须以本次 `search_law` 返回结果为准。检索不到或无法核验时，标记为“待人工核验”，不得作确定性合规结论。

#### 模块12：争议解决与适用法律

- 适用法律是否明确（中国法/英国法/CISG）
- 仲裁机构是否选择（CIETAC/HKIAC/ICC/SIAC）
- 仲裁地点是否有利
- 是否排除法院管辖

**风险分级：**

- 🟢 低风险：CIETAC仲裁 + 中国法
- 🟡 中风险：第三地仲裁（如新加坡SIAC）
- 🔴 高风险：买方所在地法院管辖

### 第三步：风险量化与报告输出（5分钟）

#### 5x5风险矩阵评估

对每个模块按以下维度评分：

| 严重程度（Severity） | 评分标准                   |
| -------------------- | -------------------------- |
| 1-轻微               | 不影响合同履行，可协商修改 |
| 2-一般               | 可能增加成本或延迟，需关注 |
| 3-较大               | 可能导致重大经济损失       |
| 4-严重               | 可能导致合同无效或重大违约 |
| 5-致命               | 可能导致企业破产或刑事责任 |

| 发生概率（Likelihood） | 评分标准                 |
| ---------------------- | ------------------------ |
| 1-罕见                 | 几乎不会发生（<5%）      |
| 2-不太可能             | 偶尔发生（5-20%）        |
| 3-可能                 | 有一定概率发生（20-50%） |
| 4-很可能               | 大概率发生（50-80%）     |
| 5-几乎确定             | 必然发生（>80%）         |

**风险值 = 严重程度 × 发生概率**

| 风险值 | 等级                | 处理策略                 |
| ------ | ------------------- | ------------------------ |
| 1-5    | 🟢 低风险（GREEN）  | 接受，记录在案           |
| 6-12   | 🟡 中风险（YELLOW） | 关注，制定应对预案       |
| 13-19  | 🟠 高风险（ORANGE） | 必须修改条款后再签署     |
| 20-25  | 🔴 致命风险（RED）  | 立即停止，重新谈判或放弃 |

## 升级决策树

遇到以下情况，建议升级至专业律师：

1. 合同金额超过100万美元
2. 涉及制裁国家/地区
3. 争议金额可能超过企业年利润
4. 涉及核心技术转让或专利许可
5. 买方要求适用外国法律且拒绝仲裁
6. 首次交易且无法核实买方资信
