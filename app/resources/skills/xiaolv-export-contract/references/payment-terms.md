# 付款方式风险对比

## 主要付款方式

### 1. T/T（电汇）

**常见组合：**

| 组合                    | 风险等级  | 适用场景         |
| ----------------------- | --------- | ---------------- |
| 100%预付                | 🟢 低风险 | 样品单、小金额   |
| 30%预付 + 70%发货前     | 🟢 低风险 | 新客户、定制产品 |
| 30%预付 + 70%见提单副本 | 🟡 中风险 | 老客户、标准产品 |
| 50%预付 + 50%见提单副本 | 🟡 中风险 | 一般贸易         |
| 100%见提单副本          | 🟠 高风险 | 仅老客户         |
| O/A 30/60/90天          | 🔴 高风险 | 战略客户+信保    |

**风险点：**

- 预付比例过低，卖方资金压力大
- 尾款后付，买方可能拒付
- 无银行信用担保

### 2. L/C（信用证）

**类型对比：**

| 类型                     | 风险等级    | 说明                   |
| ------------------------ | ----------- | ---------------------- |
| 即期信用证（Sight L/C）  | 🟢 低风险   | 见单即付，最安全       |
| 远期信用证（Usance L/C） | 🟡 中风险   | 延期付款，有利息成本   |
| 可转让信用证             | 🟡 中风险   | 中间商交易常用         |
| 背对背信用证             | 🟠 高风险   | 操作复杂，风险较高     |
| 软条款信用证             | 🔴 致命风险 | 陷阱条款，可能无法兑付 |

**信用证审查要点：**

- 开证行资信（是否在国际银行排名前列）
- 是否为保兑信用证（Confirmed L/C更安全）
- 单据要求是否可操作
- 是否存在软条款（如"需买方验货合格才付款"）

**常见软条款（陷阱）：**

1. 客检证（需买方出具检验证书）
2. 1/3正本提单直寄买方
3. 信用证暂不生效（需另行通知）
4. 指定特定船公司/船名

### 3. D/P（付款交单）

**流程：** 卖方发货 → 交单至银行 → 买方付款赎单 → 银行放单

**风险等级：** 🟡 中风险

**风险点：**

- 买方拒付，卖方承担退运或转卖成本
- 货物到港后买方拖延提货，产生滞港费
- 部分国家（如南美）D/P风险较高

**适用场景：**

- 老客户，有良好付款记录
- 货物通用性强，易于转卖
- 金额不大（<5万美元）

### 4. D/A（承兑交单）

**流程：** 卖方发货 → 交单至银行 → 买方承兑汇票 → 银行放单 → 到期付款

**风险等级：** 🟠 高风险

**风险点：**

- 买方承兑后即可提货，到期可能拒付
- 仅有商业信用，无银行担保
- 追索成本高

**适用场景：**

- 长期合作的战略客户
- 配合出口信用保险
- 买方资信良好且可核实

### 5. O/A（赊销）

**风险等级：** 🔴 高风险

**风险点：**

- 完全依赖买方信用
- 无任何担保
- 追索难度极大

**适用场景：**

- 跨国公司内部交易
- 配合出口信用保险
- 买方为国际知名大企业

## 付款方式选择矩阵

| 客户类型        | 订单金额   | 推荐付款方式              |
| --------------- | ---------- | ------------------------- |
| 新客户          | <1万美元   | T/T 100%预付              |
| 新客户          | 1-10万美元 | T/T 30%预付+70%发货前     |
| 新客户          | >10万美元  | 即期信用证                |
| 老客户（1-2年） | <5万美元   | T/T 30%预付+70%见提单副本 |
| 老客户（1-2年） | 5-20万美元 | 即期信用证或D/P           |
| 老客户（>3年）  | <10万美元  | T/T见提单副本或D/A        |
| 老客户（>3年）  | >10万美元  | 远期信用证或O/A+信保      |

## 风险防范措施

### 1. 出口信用保险

- 中国信保（Sinosure）
- 覆盖商业风险（破产、拖欠）和政治风险
- 保费通常为出口金额的0.3%-1%

### 2. 银行保函

- 预付款保函（保障买方预付款安全）
- 履约保函（保障合同履行）
- 质量保函（保障产品质量）

### 3. 资信调查

- 通过中国信保查询买方资信
- 通过邓白氏（D&B）查询
- 通过银行查询

### 4. 合同条款保护

- 约定所有权保留条款（Retention of Title）
- 约定违约金条款
- 约定争议解决条款（仲裁优于诉讼）

## 汇率风险管理

### 常见措施

1. **合同约定汇率条款**：约定汇率波动超过±3%时调整价格
2. **远期结汇**：与银行签订远期结汇协议，锁定汇率
3. **外汇期权**：购买外汇期权，对冲汇率风险
4. **多币种结算**：与买方协商使用人民币或其他稳定货币
5. **价格调整条款**：约定原材料价格波动超过一定幅度时调整合同价格

### 汇率风险示例

**场景：** 合同金额10万美元，签订时汇率6.8，收款时汇率6.5

- 预期收入：10万 × 6.8 = 68万元
- 实际收入：10万 × 6.5 = 65万元
- 汇兑损失：3万元（约4.4%）

**建议：** 合同金额>10万美元时，应约定汇率保护条款
