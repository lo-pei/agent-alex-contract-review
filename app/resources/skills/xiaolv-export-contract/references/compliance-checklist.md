# 出口合规检查清单

> 本清单只定义核验维度，不提供现行制裁或管制名单。所有名单、国家/地区措施、受限主体及法律效力状态都必须通过本次 `search_law` 和相关官方来源核验；不得把本文件作为现行事实依据。

## 一、出口管制合规

### 1. 产品是否属于管制物项

- [ ] 依《出口管制法》《两用物项出口管制条例》核验产品是否属于管制物项
- [ ] 检查《两用物项出口管制清单》（现行版）
- [ ] 检查《军品出口管理清单》
- [ ] 检查是否涉及核、生、化等敏感物项

> 以上名称仅作为核验入口，清单的现行版本、具体条目与生效状态一律以本次 `search_law` 检索结果为准。

### 2. 出口目的地风险

- [ ] 检查目的国是否在中国禁止/限制出口名单
- [ ] 检查是否涉及敏感最终用户
- [ ] 检查是否涉及军事最终用途

### 3. 最终用户核查

- [ ] 了解买方最终用途
- [ ] 了解是否有转售/转运计划
- [ ] 检查是否涉及敏感行业（军事、核能等）

## 二、国际制裁合规

### 1. 制裁名单筛查

- [ ] OFAC制裁名单（美国财政部海外资产控制办公室）
  - SDN名单（特别指定国民名单）
- [ ] EU制裁名单（欧盟）
- [ ] UN制裁名单（联合国）
- [ ] 中国《不可靠实体清单》

### 2. 涉制裁风险国家/地区

- [ ] 按合同签署和履行日期核验目的地、原产地、途经地及最终用户
- [ ] 区分全面措施、行业措施、主体名单和特定交易限制，不用固定国家清单代替逐项核验
- [ ] 核验制裁适用连接点，包括交易币种、银行、人员国籍、货物来源和技术来源
- [ ] 记录检索日期、官方来源、名单版本及命中详情；无法确认时转人工复核

### 3. 筛查方法

- OFAC官网：https://sanctionssearch.ofac.treas.gov/
- EU制裁名单：https://webgate.ec.europa.eu/fsd/fsf
- 中国信保国别风险报告

## 三、海关合规

### 1. 商品归类（HS编码）

- [ ] 确认商品HS编码准确
- [ ] 确认出口退税率
- [ ] 确认是否涉及反倾销/反补贴税

### 2. 申报合规

- [ ] 申报价格真实（低报/高报风险）
- [ ] 申报数量准确
- [ ] 原产地申报准确

### 3. 检验检疫

- [ ] 确认是否需要出口许可证
- [ ] 确认是否需要商检
- [ ] 确认目的国进口要求（认证、标准）

## 四、外汇合规

### 1. 收汇合规

- [ ] 合同金额与报关金额一致
- [ ] 收汇期限符合外汇管理局要求
- [ ] 大额收汇需提前备案

### 2. 付汇合规

- [ ] 预付款比例合理
- [ ] 佣金/折扣有合同依据
- [ ] 境外费用支付有合规凭证

### 3. 外汇风险

- [ ] 汇率波动风险管理
- [ ] 外汇账户合规使用
- [ ] 跨境资金流动合规

## 五、税务合规

### 1. 出口退税

- [ ] 退税资格确认
- [ ] 退税率确认
- [ ] 单证齐全（报关单、增值税发票、收汇凭证）

### 2. 转让定价

- [ ] 关联交易定价符合独立交易原则
- [ ] 转让定价文档齐全
- [ ] 同期资料准备

## 六、数据合规

### 1. 数据跨境

- [ ] 是否涉及个人信息跨境传输
- [ ] 是否涉及重要数据出境
- [ ] 是否需要进行数据出境安全评估

### 2. 商业秘密保护

- [ ] 技术信息保护措施
- [ ] 客户信息保护措施
- [ ] 保密协议签署

## 七、反腐败合规

### 1. 商业贿赂风险

- [ ] 禁止向公职人员行贿
- [ ] 禁止商业贿赂
- [ ] 佣金/回扣合规

### 2. 适用法律

- [ ] 中国《反不正当竞争法》
- [ ] 美国《反海外腐败法》（FCPA）
- [ ] 英国《反贿赂法》（UK Bribery Act）

## 八、知识产权保护

### 1. 产品知识产权

- [ ] 确认产品不侵犯他人专利
- [ ] 确认商标已注册（目标市场）
- [ ] 确认版权合规

### 2. OEM/ODM特殊要求

- [ ] 买方授权书
- [ ] 知识产权归属约定
- [ ] 侵权责任分担

## 九、合同合规

### 1. 必备条款

- [ ] 争议解决条款（仲裁/诉讼）
- [ ] 适用法律条款
- [ ] 不可抗力条款
- [ ] 违约责任条款

### 2. 特殊条款

- [ ] 制裁合规声明
- [ ] 出口管制声明
- [ ] 最终用户声明

## 十、保险合规

### 1. 出口信用保险

- [ ] 是否投保中国信保
- [ ] 保险额度是否充足
- [ ] 保险期限覆盖合同执行期

### 2. 货物运输保险

- [ ] 投保险别是否充分
- [ ] 保险金额是否覆盖货值110%
- [ ] 保险条款是否符合合同要求

## 快速风险评级

| 评级      | 标准                                     | 建议               |
| --------- | ---------------------------------------- | ------------------ |
| 🟢 低风险 | 目的地非制裁国、产品非管制、付款方式安全 | 正常执行           |
| 🟡 中风险 | 部分要素存在不确定性                     | 加强审查，补充信息 |
| 🔴 高风险 | 涉及制裁国/管制物项/高风险付款方式       | 暂停执行，咨询律师 |

## 免责声明

本清单仅供参考，具体合规要求请以最新法律法规为准。复杂交易建议咨询专业律师或合规顾问。
