# Incoterms 2020 贸易术语速查

## 11种贸易术语分类

### 适用于任何运输方式（7种）

| 术语 | 全称                              | 风险转移点       | 费用分担          |
| ---- | --------------------------------- | ---------------- | ----------------- |
| EXW  | Ex Works（工厂交货）              | 卖方工厂         | 买方承担全部      |
| FCA  | Free Carrier（货交承运人）        | 交给第一承运人   | 买方承担主运费    |
| CPT  | Carriage Paid To（运费付至）      | 交给第一承运人   | 卖方付主运费      |
| CIP  | Carriage and Insurance Paid To    | 交给第一承运人   | 卖方付主运费+保险（ICC(A) 一切险） |
| DAP  | Delivered at Place（目的地交货）  | 目的地（不卸货） | 卖方承担至目的地  |
| DPU  | Delivered at Place Unloaded       | 目的地（卸货后） | 卖方承担至卸货    |
| DDP  | Delivered Duty Paid（完税后交货） | 目的地（含关税） | 卖方承担全部      |

### 仅适用于海运/水运（4种）

| 术语 | 全称                            | 风险转移点 | 费用分担          |
| ---- | ------------------------------- | ---------- | ----------------- |
| FAS  | Free Alongside Ship（船边交货） | 装运港船边 | 买方承担主运费    |
| FOB  | Free on Board（船上交货）       | 装运港船上 | 买方承担主运费    |
| CFR  | Cost and Freight（成本加运费）  | 装运港船上 | 卖方付主运费      |
| CIF  | Cost, Insurance and Freight     | 装运港船上 | 卖方付主运费+保险（ICC(C) 最低险别） |

> **Incoterms 2020 的关键变化**：CIP 的卖方投保义务由最低险别提升为 **ICC(A) 一切险**；CIF 仍维持 **ICC(C) 最低险别**。核对保险条款时须区分两者，不能默认「CIP = CIF + 运费 + 保险」。

## 常用术语对比（出口场景）

### EXW vs FCA

| 对比项   | EXW              | FCA                |
| -------- | ---------------- | ------------------ |
| 出口清关 | 买方负责         | 卖方负责           |
| 装货义务 | 买方             | 卖方（如指定地点） |
| 适用场景 | 买方在国内有代理 | 卖方协助出口       |

### FOB vs CIF

| 对比项   | FOB               | CIF                  |
| -------- | ----------------- | -------------------- |
| 保险     | 买方自行投保      | 卖方投保（ICC(C) 最低险别） |
| 运费     | 买方承担          | 卖方承担             |
| 成本构成 | 货物成本+国内费用 | FOB+主运费+保险费    |
| 适用场景 | 买方指定货代      | 卖方安排运输         |

### CFR vs CIF

| 对比项 | CFR              | CIF                    |
| ------ | ---------------- | ---------------------- |
| 保险   | 买方负责         | 卖方负责               |
| 单据   | 提单             | 提单+保险单            |
| 风险   | 买方承担运输风险 | 卖方转移风险但承担保费 |

## 风险点提示

### 1. 术语与运输方式不匹配

❌ 错误：空运货物使用FOB
✅ 正确：空运应使用FCA

### 2. 风险转移点理解错误

❌ 错误：认为CIF下卖方承担运输途中风险
✅ 正确：CIF风险在装运港船上转移，卖方仅承担保费

### 3. 未约定具体地点

❌ 错误：合同仅写"FCA"
✅ 正确：应写明"FCA Shanghai Airport"

### 4. 与付款方式冲突

❌ 风险：EXW + 信用证（买方难以控制单据）
✅ 建议：EXW配合T/T预付

## 选择建议

| 场景            | 推荐术语 | 理由                      |
| --------------- | -------- | ------------------------- |
| 首次交易/新客户 | CIF      | 卖方控制运输，降低风险    |
| 买方指定货代    | FOB      | 配合买方物流体系          |
| 内陆交货        | FCA      | 比EXW更合理，卖方协助清关 |
| 门到门          | DAP      | 卖方全程负责，买方省心    |
| 小包裹/样品     | CIP      | 含保险，安全性高          |

## 常见纠纷

1. **装船费分担**：FOB下装船费由谁承担？建议在合同中明确
2. **保险险别**：CIF下卖方仅需投保最低险别（ICC-C），买方需加保要另付
3. **卸货费**：DAP下卸货费由买方承担，DPU下由卖方承担
4. **出口许可**：EXW下出口许可由买方办理，可能面临无法出口风险
