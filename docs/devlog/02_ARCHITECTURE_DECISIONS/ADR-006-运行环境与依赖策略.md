# ADR-006：运行环境与依赖策略

- 状态：**已接受（用户 2026-10-26 回复“按建议继续”，确认 Python 3.12 等默认建议）**
- 日期：2026-10-26
- 决策人：用户 + Trae AI
- 关联：`开发提示词.md` 技术栈约束；ISSUE-003 / ISSUE-004 / ISSUE-007
- 影响范围：`pyproject.toml` / `requirements.txt`、`.env.example`、README、CI、本地运行

---

## 1. 背景

`开发提示词.md` 写的是“Python 3.9+”，但 2026-10-26 查询 PyPI 的实际要求是：

| 包 | 最新版本 | requires-python |
|---|---|---|
| LangGraph | 1.2.17 | ≥3.10 |
| LangChain | 1.4.7 | ≥3.10 |
| langchain-openai | 1.7.2 | ≥3.10 |
| langgraph-checkpoint-sqlite | 3.1.2 | ≥3.10 |
| FastAPI | 0.162.0 | ≥3.10 |
| Uvicorn | 0.54.0 | ≥3.10 |
| Pydantic | 2.14.1 | ≥3.10 |
| Streamlit | 1.66.1 | **≥3.11** |
| pytest | 9.1.1 | ≥3.10 |
| pypdf | 6.21.2 | ≥3.9 |
| python-docx | 1.2.0 | ≥3.9 |

本机默认 `python` 是 3.14，另有 `py -3.12` 可用。若强行支持 3.9，只能锁 LangGraph 0.2.x / Streamlit 旧版，HITL API 与文档能力受限，且需要额外兼容测试。

---

## 2. 可选方案

| 方案 | 描述 | 优点 | 缺点 |
|---|---|---|---|
| A. Python 3.9 + 旧版依赖 | 严格满足文档字面要求 | 字面合规 | LangGraph/Streamlit 版本老；HITL/checkpointer API 受限；维护成本高；与调研代码/文档不一致 |
| B. Python 3.11 | 满足 Streamlit 要求 | 稳定；兼容性好 | 本机未装，需要额外安装 |
| C. Python 3.12 | 使用当前最新依赖 | 本机已装；满足所有依赖；LangGraph 1.x HITL 完整 | 与文档“3.9+”字面不一致，需要在 README 说明 |
| D. Python 3.14 | 本机默认 | 最新 | 生态兼容性风险；部分包可能未发布 3.14 wheel；不作为项目基线 |

---

## 3. 决策

**采用 C：Python 3.12 + 当前最新稳定依赖 + venv 隔离。**

### 3.1 解释器与虚拟环境

```powershell
cd "d:\A项目\Agent_Alex外贸合同智审助手"
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
```

- 所有命令显式使用 `.venv\Scripts\python.exe`，不依赖系统默认 `python`；
- `.venv/` 加入 `.gitignore`；
- 不在项目内提交解释器/虚拟环境。

### 3.2 依赖清单（2026-10-26 最新稳定版）

```text
langgraph==1.2.17
langchain==1.4.7
langchain-openai==1.7.2
langgraph-checkpoint-sqlite==3.1.2
fastapi==0.162.0
uvicorn==0.54.0
streamlit==1.66.1
pydantic==2.14.1
python-docx==1.2.0
pypdf==6.21.2
python-dotenv==1.2.4
pytest==9.1.1
pytest-asyncio==1.4.1
ruff==0.17.2
```

**传递依赖（由 pip 自动安装，不单独锁定）**：

- `langgraph-checkpoint-sqlite==3.1.2` 依赖 `aiosqlite>=0.20`、`langgraph-checkpoint>=4.3,<5`、`sqlite-vec>=0.1.6`；
- `sqlite-vec` 有 Windows amd64 wheel（`py3-none-win_amd64`），Python 3.12 可用；
- `langchain` / `langchain-openai` 会带入 `langchain-core`、`openai`、`httpx` 等；实际版本以 `pip freeze` 为准。

**已验证的 API 细节（2026-10-26 下载 wheel 检查，未安装到项目环境）**：

| 项 | 结论 |
|---|---|
| `interrupt(value, *, response_schema=...)` | `langgraph==1.2.17` 支持 `response_schema`；图 resume 会从节点顶部重跑 |
| `Command(resume=...)` | 从 `langgraph.types` 导入；与 `interrupt()` 配套 |
| `StateGraph.compile(checkpointer=...)` | 签名已核对 |
| `AsyncSqliteSaver` | 从 `langgraph.checkpoint.sqlite.aio` 导入，不是顶层包；`from_conn_string` 是异步上下文管理器 |
| `InMemorySaver` | 从 `langgraph.checkpoint.memory` 导入 |

- 依赖锁文件：`requirements.txt`（运行）与 `requirements-dev.txt`（测试/格式化），或 `pyproject.toml` + lock；二选一，阶段 3 创建时确定；
- 不引入 `langchain-community` 等大包，除非某个功能确实需要；
- 不引入 `PyMuPDF`（AGPL/商业许可）、不引入 Postgres/Redis/Celery；
- 若安装时发现版本冲突，以实际可解析的最近版本为准，并把最终版本写回锁文件与本 ADR 的“实际安装结果”一节。

### 3.3 LLM 接入

- 统一抽象为 **OpenAI 兼容接口**：
  ```dotenv
  LLM_PROVIDER=openai_compatible
  LLM_BASE_URL=https://api.openai.com/v1
  LLM_API_KEY=
  LLM_MODEL=gpt-4.1-mini
  LLM_TIMEOUT_SECONDS=60
  LLM_MAX_REPAIR_RETRIES=1
  ```
- 代码不写死厂商/模型；通过 `langchain-openai` 的 `ChatOpenAI(base_url=..., api_key=..., model=...)`；
- 结构化输出优先 `with_structured_output(method="json_schema")`；供应商不支持时回退 `function_calling`，Pydantic 校验不变；
- 无 Key 时的行为：
  - 规则评测、单元测试、最小图（无 LLM）可运行；
  - 全链路演示需要 Key；缺失时明确报错，不静默用假数据冒充；
  - 测试用 `FakeChatModel` / 脚本化 LLM，不联网。
- Key 只放 `.env`，`.env` 进 `.gitignore`；代码/日志/README 不出现 Key。

### 3.4 存储与前端

- checkpoint：SQLite（见 ADR-004）；
- 报告/pending：本地 `.data/` JSON；
- API：FastAPI + Uvicorn；
- UI：Streamlit 单页，只做上传、运行、展示/确认、下载；
- 不使用 Docker、不使用 React/Vue、不使用低代码平台、不使用 RAG 知识库/向量库。

### 3.5 文档解析依赖

- PDF：`pypdf`（BSD）；
- DOCX：`python-docx`；
- TXT/MD：标准库；
- 不默认引入 PyMuPDF；OCR 不在 MVP 范围（见 ADR-005）。

## 4. 被否决方案及原因

| 方案 | 否决原因 |
|---|---|
| Python 3.9 | 当前 LangGraph/Streamlit 不支持；锁旧版会牺牲 HITL 与维护性 |
| Python 3.11 | 可行，但本机未装；3.12 已装且满足全部依赖 |
| Python 3.14（默认） | 生态兼容性未验证；不作为项目基线 |
| 锁定 LangChain 0.2/0.3 旧栈 | 与调研项目/当前文档不一致；HITL/checkpointer 行为差异大 |
| 引入 PyMuPDF | 许可证不确定性；MVP 不需要 |
| Docker 交付 | 明确禁止；本地运行足够 |
| 把 Key 写进代码/配置默认值 | 安全事故；必须环境变量 |

## 5. 后果

### 正面

- 依赖与当前 LangGraph HITL/checkpointer 行为一致；
- 本机可直接用 3.12 跑；测试/演示环境明确；
- 无外部数据库/容器依赖，启动简单；
- LLM 供应商可替换，不被单一厂商锁定。

### 代价与风险

- 与 `开发提示词.md` 的“3.9+”字面不一致，必须在 README 与答辩中说明原因（不是偷懒，是依赖硬要求）；
- 最新版本可能存在未发现的兼容问题；阶段 3 首次安装后需记录实际版本并跑通最小图；
- `langchain-openai` 对某些国内兼容接口的 `json_schema` 支持不一致，需要回退路径；
- Python 3.12 与 3.14 的差异可能导致系统默认 `python` 命令误用；所有命令显式 `.venv`；
- Streamlit 1.66.1 的 API 变化需要在 UI 实现时确认（如 `st.rerun`、`st.file_uploader`）。

### 对后续模块的影响

- CI/测试统一 3.12；
- README 必须写“Python 3.12（原需求 3.9+，因 2026 依赖要求调整）”；
- `.env.example` 必须提供，但不含真实 Key；
- 依赖锁文件变更需要同步 ADR-006 的“实际安装结果”。
